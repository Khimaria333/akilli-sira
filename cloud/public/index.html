Ahenk
Şarkıdan şarkıya, ahenkle.
  • 🎧Spotify'da müziğini her zamanki gibi aç: iPhone, Android, bilgisayar, hoparlör fark etmez.
  • 🎯Ahenk çalan şarkının tarzına, dönemine, temposuna ve ruh haline en uygun sıradaki şarkıyı seçer.
  • ⏭Şarkı bitmeden Spotify'ın sırasına ekler. Telefonun kilitliyken bile çalışır, uygulama açık kalmak zorunda değil.
Spotify'ı bağla
Spotify'ın kuralı gereği herkes kendi ücretsiz anahtarını alır ve Spotify Premium gerekir. Bir kere yapılır (3 dk):
  1. Spotify geliştirici panelini aç, Spotify hesabınla gir
  2. Create app → Ad: Ahenk, açıklama: kişisel
  3. Redirect URI kutusuna şu adresi yapıştır, Add de:
  1. Web API kutusunu işaretle ve kaydet
  2. Uygulamanın sayfasındaki Client ID'yi kopyala, aşağıya yapıştır
Arkadaşın senin anahtarını kullanacaksa: panelde User Management'a onun Spotify e-postasını ekle (en fazla 5 kişi).
Ahenk kişisel bir projedir; Spotify'ın resmi bir parçası değildir.
